# Crypto Due Diligence Framework

**Author:** Joe Nasr  
**Identity:** https://linktr.ee/joenasr/

A static reference for organizing open-source due diligence on cryptocurrency projects, exchanges, tokens, and DeFi protocols.

## Current status

Research-note and checklist page.

The repository contains a README and a static HTML reference page. It does **not** contain a live blockchain scanner, automated fraud detector, wallet-clustering engine, real-time alerting system, smart-contract auditor, exchange surveillance service, or incident-response platform.

## What the framework does

It organizes questions around six evidence areas:

1. Entity identity and regulatory claims
2. Smart-contract and code review
3. Token, liquidity, and asset-control structure
4. On-chain concentration and transaction patterns
5. Domain, infrastructure, and public-document consistency
6. Social, market, and promotional claims

The purpose is to help a reviewer decide what should be verified and where evidence is missing. A red flag is not proof of fraud, and the absence of a red flag is not proof of legitimacy.

## Evidence boundary

Cryptocurrency risk assessment can involve legal, financial, technical, and jurisdiction-specific questions. This repository is not financial advice, legal advice, a regulatory determination, or a substitute for qualified security review. Claims about a named project should be checked against primary records and current official sources before use.
